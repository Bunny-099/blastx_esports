--------------------------------------------------------------------------------
1. WORKFLOW OVERVIEW
--------------------------------------------------------------------------------
Current Flow Update:
- Jab user tournament par "JOIN NOW" click karta hai, toh woh DIRECTLY register nahi hoga.
- User pehle "CREATE TEAM" ya "JOIN TEAM (via code)" karega.
- Team lobby me tab tak team "forming / unregistered" status me rahegi.
- Condition: Tournament register karne ke liye team me EXACTLY 4 MAIN PLAYERS mandatory hain.
- Jab 4 players join ho jaayenge, tab Team Captain "REGISTER TOURNAMENT" button dabaayega.
- Backend registration logic check karega (4 players check, entry fee check, etc.) aur status "REGISTERED" mark karke roster lock kar dega.
- Registration ke baad users ko Registered Teams ki List (2-column grid API) aur Live Custom Room Details (Room ID & Password) milenge.

--------------------------------------------------------------------------------
2. REQUIRED BACKEND ENDPOINTS & LOGIC
--------------------------------------------------------------------------------

--------------------------------------------------------------------------------
API 1: Create Team
--------------------------------------------------------------------------------
Endpoint: POST /v1/tournaments/:id/teams
Headers: Authorization: Bearer <user_token>

Request Body:
{
  "name": "BLX WARRIORS",
  "tag": "BLX",
  "logo_url": "optional_url",
  "accepting_substitutes": true,
  "player": {
    "name": "Player One",
    "ign": "BLX_Leader",
    "uid": "123456789"
  }
}

Backend Logic:
- Team create karo, random unique invite_code generate karo (e.g. "BLX7K9").
- Creator ko Captain + MAIN player banakar team_members table me add karo.
- Initial status = "FORMING", is_registered = false.

Response (201 Created):
{
  "status": "success",
  "data": {
    "id": "team_123",
    "tournament_id": "tour_456",
    "name": "BLX WARRIORS",
    "tag": "BLX",
    "code": "BLX7K9",
    "captain_id": "user_789",
    "is_registered": false,
    "members": [
      {
        "user_id": "user_789",
        "name": "Player One",
        "ign": "BLX_Leader",
        "uid": "123456789",
        "role": "CAPTAIN",
        "roster_type": "MAIN"
      }
    ]
  }
}

--------------------------------------------------------------------------------
API 3: Join Team
--------------------------------------------------------------------------------
Endpoint: POST /v1/teams/:teamId/join
Headers: Authorization: Bearer <user_token>

Request Body:
{
  "invite_code": "BLX7K9",
  "rosterType": "MAIN",
  "player": {
    "name": "Player Two",
    "ign": "BLX_Pro",
    "uid": "987654321"
  }
}

Backend Logic:
- Verify karo user pehle se kisi aur team me na ho is tournament me.
- Check main slots limit (Max 4 main players).
- If main slots full and accepting_substitutes = true, assign roster_type = "SUBSTITUTE".
- Return updated team object.

--------------------------------------------------------------------------------
API 4: Register Team for Tournament (CRITICAL VALIDATION)
--------------------------------------------------------------------------------
Endpoint: POST /v1/tournaments/:id/register
Headers: Authorization: Bearer <captain_token>

Request Body:
{
  "team_id": "team_123"
}

Backend Business Rules & Validations:
1. Verify requester is Team Captain.
2. Verify main_members count EXACTLY == 4.
   - If main_members < 4, return error 400 Bad Request:
     {
       "status": "error",
       "code": "INVALID_MEMBER_COUNT",
       "message": "Tournament registration requires exactly 4 main players in your team."
     }
3. Check tournament max teams limit (e.g., 50 teams limit).
4. If tournament entry fee > 0, check wallet balance & deduct entry fee.
5. Mark team status as "REGISTERED" / "CONFIRMED" and set roster lock (no member add/remove allowed after this).

Response (200 OK):
{
  "status": "success",
  "message": "Team successfully registered for tournament",
  "data": {
    "registration_id": "reg_999",
    "tournament_id": "tour_456",
    "team_id": "team_123",
    "registered_at": "2026-10-03T18:00:00Z"
  }
}

--------------------------------------------------------------------------------
API 6: Get Custom Room Details (For Players)
--------------------------------------------------------------------------------
Endpoint: GET /v1/tournaments/:id/room
Headers: Authorization: Bearer <registered_user_token>

Validation:
- User ki team registered honi chahiye.
- Tournament status "LIVE" hona chahiye (ya room reveal time pass ho gaya ho).
- Agar registered nahi hai -> return 403 Forbidden with code "NOT_REGISTERED".
- Agar abhi release nahi hua -> return 425 Too Early with code "ROOM_NOT_AVAILABLE" & reveal_at timestamp.

Response (200 OK):
{
  "status": "success",
  "data": {
    "room_id": "8745210",
    "password": "BLX99",
    "starts_at": "2026-10-03T19:00:00Z",
    "status": "READY"
  }
}
